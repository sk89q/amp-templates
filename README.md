# AMP Templates

Custom templates for [CubeCoders AMP](https://cubecoders.com/AMP).

## Templates

| Template | Platform | Source |
|---|---|---|
| ReSkate | Windows | [Dingo-Shenanigans/ReSkate](https://github.com/Dingo-Shenanigans/ReSkate) |

## Usage

Add `<owner>/<repo>:main` to **Configuration Repositories** in ADS, then **Fetch Latest**.
